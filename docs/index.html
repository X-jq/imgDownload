安装步骤

三步装好，立即可用

以 Chrome 开发者模式加载本地扩展，无需上架商店。

  1. 1

    打开扩展管理页

    在 Chrome 地址栏输入 chrome://extensions/ 并回车。

  2. 2

    开启开发者模式

    打开页面右上角的「开发者模式」开关。

  3. 3

    加载已解压的扩展程序

    点击左上角「加载已解压的扩展程序」，选择插件根目录（包含 manifest.json 的文件夹）。

  4. 4

    开始使用

    进入淘宝 / 京东 / 拼多多商家版的商品详情页，右下角会出现「获取图片」按钮，点击即可抓取。
